## Description

I kept playing Nuzlockes with half the browser dedicated to reference tabs. MyPokePanion is what I wished existed instead.

Free fan-built toolkit for PC players:

- **Pokédex** — all 1025 Pokémon, fast search in EN/DE
- **Region maps** — encounter locations, items, trainers (Kanto–Unova)
- **Nuzlocke tracker** — solo offline or real-time multiplayer with friends
- **Team builder** — legality checks, Smogon sets, Showdown export
- **Versus lab** — gen-accurate damage calc *and* a turn-by-turn **1v1 battle simulator** from the same matchup screen

Dark UI, high information density, no ads. Hobby project I update regularly.

Not affiliated with Nintendo. Feedback welcome: https://mypokepanion.com/en/feedback
