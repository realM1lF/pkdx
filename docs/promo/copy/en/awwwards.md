**URL:** https://mypokepanion.com/en

**Project title:** MyPokePanion

**Short description:**

A bilingual Pokémon companion for players at their desk — not an encyclopedia, an operations deck. Dark Holo-Dex aesthetic: type-energy colors, gold accents, animated sprites, scroll-driven home hero (Three.js particles, GSAP). Bundles dex, region maps, Nuzlocke tracking, team builder, damage calc, and a playable 1v1 battle simulator in one React SPA.

**Longer description (case study / project page):**

I built MyPokePanion because Nuzlocke runs kept turning my second monitor into a tab graveyard. I wanted something that looked and felt like a modern game UI — dense, reactive, fun to click through — while still being a serious reference tool.

The design system ("Holo-Dex") treats Pokémon types as energy colors across every surface. Information density is intentional: compact cards, 36–44px rows, micro-labels. Motion is functional — hover glows, scroll reveals, sprite loading skeletons — not decoration for its own sake.

Technically: React 19, TypeScript, Vite, Tailwind, framer-motion, GSAP ScrollTrigger, Lenis smooth scroll, Three.js on the home hero. Full EN/DE via URL routing (/en, /de) with SEO prerender on content routes. Versus lab uses @smogon/calc for ranges and @pkmn/sim for the turn-by-turn battle arena (lazy-loaded chunk).

Fan project. Free. No ads. Still actively developed.
